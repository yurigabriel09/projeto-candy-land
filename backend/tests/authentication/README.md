# `tests/authentication/`

- `test_account_identity.py`: regras de resolução/normalização de email e telefone e identidade de conta.
- `test_facebook_mobile_callback.py`: callback/ticket do fluxo Facebook mobile.
- `test_oauth_providers.py`: integração lógica dos provedores OAuth.
- `test_single_channel_mobile_login.py`: login mobile escolhendo um canal de identificação (email ou telefone), sem exigir ambos.
