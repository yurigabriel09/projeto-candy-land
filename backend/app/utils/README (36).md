# `backend/app/utils/`

- `__init__.py`: inicialização do pacote de utilitários.
- `auth_decorator.py`: decorators de autenticação JWT e verificação de tipo/propriedade de conta.
- `datetime_utils.py`: conversões e operações de data/hora consistentes.
- `formatter.py`: normalização e formatação de dados para respostas/uso interno.
- `image_upload.py`: tratamento e armazenamento de imagens enviadas.

Utilitários devem ser genéricos e sem regras de negócio específicas de checkout ou restaurante.
