# `backend/app/config/`

- `config.py`: concentra classes/valores de configuração da aplicação, incluindo banco, segurança e integrações lidas do ambiente.

Não inserir tokens, senhas, client secrets ou chaves reais neste diretório. Variáveis novas devem ser documentadas em `backend/.env.example` com valor vazio/fictício e validadas para falhar com mensagem clara quando obrigatórias.
