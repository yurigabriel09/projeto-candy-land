# `mobile/app/src/main/`

- `AndroidManifest.xml`: declara componentes, permissões, deep links e serviços do app.
- `java/`: código Kotlin organizado por pacote. A implementação principal está em `com/candyland/mobile/` e o protótipo em `com/example/candyland/`.
- `res/`: recursos Android (drawables, ícones adaptativos, strings, temas e regras XML).
- `keepRules/rules.keep`: regras para manter classes/membros necessários em builds com shrinker/obfuscation.
