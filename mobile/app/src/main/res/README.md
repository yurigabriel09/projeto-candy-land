# `mobile/app/src/main/res/`

- `drawable/`: camadas XML do ícone do launcher.
- `mipmap-anydpi-v26/`: ícones adaptativos XML.
- `mipmap-hdpi/`, `mipmap-mdpi/`, `mipmap-xhdpi/`, `mipmap-xxhdpi/`, `mipmap-xxxhdpi/`: variantes rasterizadas do ícone para densidades de tela.
- `values/colors.xml`: cores nomeadas.
- `values/strings.xml`: textos e rótulos do app.
- `values/styles.xml` e `values/themes.xml`: estilos/tema Android.
- `xml/backup_rules.xml` e `data_extraction_rules.xml`: políticas de backup e extração de dados.

Não armazenar tokens, URLs privadas ou dados pessoais em recursos versionados.
