# `scripts/` — automações de desenvolvimento

- `gerar_zip_limpo.cmd`: atalho Windows para geração do ZIP limpo.
- `gerar_zip_limpo.ps1`: implementação PowerShell da geração de ZIP sem dependências/arquivos temporários.
- `gerenciar_pr.cmd`: atalho Windows para operações auxiliares de Pull Request.
- `gerenciar_pr.ps1`: implementação PowerShell do gerenciamento de PR.
- `preparar_ambiente.cmd`: atalho Windows para preparação inicial.
- `preparar_ambiente.ps1`: implementação PowerShell da preparação de ambiente.

Antes de executar scripts, ler o conteúdo e conferir o diretório/branch alvo. Scripts devem falhar de forma segura quando houver alterações locais não commitadas.
