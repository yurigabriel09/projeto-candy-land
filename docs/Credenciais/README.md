# `docs/Credenciais/`

Reúne instruções ilustradas para configurar serviços externos.

- `Guia.txt`: índice/orientação geral dos materiais.
- `Brevo/`: email transacional e chave de API.
- `Facebook/`: configuração do app Facebook e credenciais OAuth.
- `Google/`: projeto Google Cloud, OAuth e Maps.
- `Twilio/`: WhatsApp/SMS e chaves da conta.

**Segurança:** as capturas de tela não foram inspecionadas visualmente nesta revisão. Verificar se API keys, client secrets, tokens e identificadores privados estão ocultos. Se algum segredo real estiver no Git, revogar/rotacionar no fornecedor e remover o segredo do histórico conforme política.
