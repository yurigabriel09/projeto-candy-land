# `frontend/src/utils/`

- `categoryTypes.js`: constantes e normalização de tipos de categoria.
- `countries.js`: dados de países/DDD ou apoio aos campos de telefone/endereço.
- `imageUrl.js`: normalização de URL/caminho de imagem.
- `masks.js`: máscaras de entrada para campos formatados.
- `pushNotification.js`: integração/registro de notificações web no navegador.
- `validators.js`: validadores reutilizáveis de formulários.
